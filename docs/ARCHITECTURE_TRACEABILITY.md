## 3. Integration Integrity Findings

### Verified Direct Call Paths
1. **Target Enrolment to Assessment Execution:**
   `ScopeTarget` (Created & Authorized) $\to$ `ScopeEngine.validate_target_in_scope` $\to$ Snapshot generated $\to$ `AssessmentJob` (`QUEUED`) $\to$ Worker claim (`PREFLIGHT`) $\to$ Boundary re-validation $\to$ Execution in Win32 Job Object $\to$ Adapter execution $\to$ Raw evidence persisted $\to$ SHA-256 hash verified.
2. **Finding Observation to Risk Recalculation:**
   Raw tool finding $\to$ `FindingDeduplicationService` $\to$ Canonical `VulnerabilityFinding` updated or inserted $\to$ Graph vertex synchronized $\to$ `ContextualRiskService` calculates inherent/residual score $\to$ Attack path engine updates chokepoints.
3. **Remediation Sign-off to Independent Retest:**
   Finding confirmed $\to$ NIST control guidance mapped $\to$ Lead approval $\to$ Remediation attempted $\to$ Independent retest dispatched $\to$ 4-outcome verification $\to$ Finding closed or reopened $\to$ Risk score updated to 0.0 or penalized.
4. **Health Diagnostics to Controlled Self-Healing:**
   12-subsystem live probe $\to$ Diagnostic sweep runs 10 read-only checks $\to$ Confirmed defects mapped to Failure Knowledge Base $\to$ Pre-condition snapshot $\to$ Bounded idempotent recovery executed $\to$ Post-condition snapshot re-evaluated $\to$ Logged to decision ledger.

### Architectural Inconsistencies Closed in Prompt 13
1. **Audit Chain Monotonicity under Concurrent Writes:** Added process-level serialization (`_chain_lock`) and microsecond monotonic adjustments to guarantee strictly sequential timestamps and unbroken hash chaining.
2. **Finding Transition Race Conditions:** Added `expected_status` optimistic concurrency check to `FindingTransitionRequest`, returning HTTP 409 Conflict if finding state changed concurrently.
3. **Audit Ledger Verification Classification:** Enhanced `verify_audit_ledger_integrity` to explicitly categorize ledger status into `VALID`, `TAMPERED`, `EMPTY`, or `LEGACY_UNVERIFIED`.
